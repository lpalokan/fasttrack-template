# Coaching log

Repeated weaknesses, on either side, carried into the next session.

Append a line only when the same weakness has been observed twice. One
occurrence is noise; two is a pattern worth a session's attention. Tag
agent-side entries `[agent]` and owner-side entries `[owner]`, because a
session that reads this file benefits from knowing its predecessors' failure
modes.

Format: `- YYYY-MM-DD — [agent|owner] What happened, twice, and where. What
would prevent it.`

When an entry keeps recurring, it is a candidate for a mechanism: a hook, a
test or a setting (AGENTS.md, "Mechanisms, not prose").
